# THEBENUA SHOP — Telegram-бот

Бот продажи цифровых товаров: aiogram 3 + SQLite, оплата CryptoBot и Telegram Stars (1 ⭐ = 1.5 ₽).

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить токены
python bot.py
```

## .env

- `BOT_TOKEN` — токен бота от @BotFather
- `ADMIN_IDS` — ID админов через запятую (доступ к /admin)
- `CRYPTOBOT_TOKEN` — токен Crypto Pay API от @CryptoBot (Crypto Pay → Create App)
- `SUPPORT_URL` — ссылка на поддержку

## Возможности

- Главное меню: Каталог, Профиль, О магазине, Поддержка, Информация, Язык
- Профиль: баланс, потрачено, пополнение (CryptoBot / звёзды), промокоды
- /admin: создание категорий и товаров (цена, количество, содержимое), промокоды, статистика (юзеры, доход день/неделя/месяц/год/всё время, рефералы, наличие), рассылка (премиум-эмодзи, фото, линк-кнопка)
- Оплата товара: CryptoBot (счёт, авто-проверка оплаты), звёзды, баланс — после оплаты бот сразу выдаёт товар
- Цветные кнопки (style) и премиум-эмодзи в кнопках/тексте через прямые вызовы Bot API
- Баннер `assets/banner.png` генерируется скриптом `make_banner.py`

## Пользователи и история действий

`/admin` → **Пользователи** → выберите человека. Список отсортирован по последней
активности и разбит на страницы. Карточка показывает имя, ID, актуальный юзернейм,
первый запуск, последнюю активность, баланс, расходы и историю.
Время отображается по Самаре (UTC+4).

Журнал сохраняет нажатия разделов, категорий, товаров и способов оплаты.
Нажатие кнопки оплаты не означает успешную покупку: покупки и пополнения
отображаются отдельно по существующим записям базы. Тексты сообщений,
промокоды и содержимое выданных товаров в журнал не копируются.
Переходы по внешним ссылкам Telegram боту не сообщает.

Просмотры доступны только с момента установки обновления. Старые покупки и
пополнения видны сразу; имена и актуальные юзернеймы старых пользователей
обновятся при следующем взаимодействии. Доступ — только для `ADMIN_IDS`.

Перед обновлением скачайте резервную копию командой `/backup`. Загрузите
`bot.py` и `user_activity.py` в одну папку на хостинге и перезапустите процесс.
Сохраните существующие `.env` и файл базы по `DB_PATH` (по умолчанию `shop.db`).
Новые таблица и поля создадутся при запуске автоматически.

Проверка: `python -m unittest -v test_user_activity`.
