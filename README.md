# THEBENUA SHOP — Telegram-бот

Бот продажи цифровых товаров: aiogram 3 + SQLite, оплата CryptoBot и Telegram Stars (1 ⭐ = 1.5 ₽).

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить токены
python bot.py
```

## .env

- `BOT_TOKEN` — токен бота от @BotFather
- `ADMIN_IDS` — ID админов через запятую (доступ к /admin)
- `CRYPTOBOT_TOKEN` — токен Crypto Pay API от @CryptoBot (Crypto Pay → Create App)
- `SUPPORT_URL` — ссылка на поддержку

## Возможности

- Главное меню: Каталог, Профиль, О магазине, Поддержка, Информация, Язык
- Профиль: баланс, потрачено, пополнение (CryptoBot / звёзды), промокоды
- /admin: создание категорий и товаров (цена, количество, содержимое), промокоды, статистика (юзеры, доход день/неделя/месяц/год/всё время, рефералы, наличие), рассылка (премиум-эмодзи, фото, линк-кнопка)
- Оплата товара: CryptoBot (счёт, авто-проверка оплаты), звёзды, баланс — после оплаты бот сразу выдаёт товар
- Цветные кнопки (style) и премиум-эмодзи в кнопках/тексте через прямые вызовы Bot API
- Баннер `assets/banner.png` генерируется скриптом `make_banner.py`
